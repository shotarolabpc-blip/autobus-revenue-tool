# 15-64歳の係数の作り方（Q3）：B と B′ の精度確認

実施：2026-10-15　スクリプト：`data_build/age_weights_accuracy.py`（`.venv\Scripts\python data_buildge_weights_accuracy.py`）

## 何を比べたか

15-64歳の係数は、調査の3区分（15〜29歳・30〜49歳・50〜64歳）の値から作る。区分ごとに
**外出率 × トリップ数 × バス分担率を掛けた値**を出し、3区分を人口の構成比で重み付けして足し合わせる。
重みの決め方が違う2つを比べた。

| 記号 | 重みの決め方 | 人口データ |
|---|---|---|
| **B** | 勢圏（円）の、5歳刻みの推計人口で決める（いちばん細かい） | 6区分以上の人口データが必要 |
| **B′** | 勢圏がある**市区町村全体**の、その年次の5歳刻みの推計人口で決める | 4区分のまま（市区町村ごとの構成比を別に配信） |

## 条件

- 勢圏：東京都の16か所（区部9・多摩7。駅の位置など）、半径 300m と 500m
- 年次：2025年と2040年（国土数値情報 R6国政局推計、各メッシュの5歳階級 PT04〜PT13）
- 日：平日と休日
- 係数：全国都市交通特性調査（令和3年）の3区分の値。都市類型は、区部は「三大都市圏／中心都市」、多摩は「三大都市圏／周辺都市１」で計算
  （比較のための割り当てで、都市類型の判定ルールではない）
- 勢圏の人口は、メッシュとの重なりの面積で按分（実際の計算と同じ考え方）。秘匿・合算メッシュのまとめ方は省略（BとB′の両方に共通で、差への影響は小さい）
- 差は「B′ ÷ B − 1」。比べる量は2つ：
  1. 15-64歳の**1人1日あたり**の値
  2. 勢圏全体の**延べ乗車人員**（4年齢階層の合計。15-64歳以外はBとB′で同じ）

## 結果（要約）

全128通り（16か所 × 半径2 × 年次2 × 日2）。

| | 平均 | 中央値 | 最大 | 1%を超えた件数 |
|---|---|---|---|---|
| 15-64歳の1人1日あたり | 1.54% | 1.27% | **6.60%** | 78 / 128 |
| **勢圏全体の延べ乗車人員** | 0.82% | 0.69% | **2.88%** | 36 / 128 |

内訳（絶対値の平均）：

| | 15-64歳の値 | 延べ乗車人員 |
|---|---|---|
| 区部・平日 | 1.59% | 0.85% |
| 区部・休日 | 1.06% | 0.63% |
| 多摩・平日 | 0.98% | 0.60% |
| **多摩・休日** | **2.64%** | **1.24%** |
| 2025年 | 1.66% | 0.95% |
| 2040年 | 1.42% | 0.69% |

## 読み取り

- 延べ乗車人員の差は、**平均では1%以内（0.82%）**だが、**28%の勢圏（36/128）で1%を超え、最大は2.88%**（府中駅・半径300m・2040年・休日）。
- 15-64歳の1人1日あたりの値で見ると、平均1.54%・最大6.60%で、1%程度には収まらない。
- 差は、**休日と多摩地域で大きい**（多摩・休日の延べ乗車人員は平均1.24%）。休日は、15〜29歳と30〜49歳の係数の違いが大きく、重みのずれが効くため。
- 符号は一定ではない（B′が大きい勢圏も小さい勢圏もある）。年次でも変わる（立川駅・半径300m・休日の15-64歳の値は、2025年にB′が +4.3%、2040年に −1.8%）。
- 差が最大の勢圏（府中駅・2040年）では、重みが B：15〜29歳 0.314／30〜49歳 0.307／50〜64歳 0.379、B′：0.274／0.409／0.317 と、勢圏と市全体で年齢構成が違う（駅前の勢圏は30〜49歳の割合が低く、15〜29歳と50〜64歳の割合が高い）。

## 判断の目安

ご指示の「差が1%程度に収まらない場合は実装を止める」に当てはまると判断し、**B′ の実装は保留**した。
ただし、1%は判断の目安で根拠のある基準ではない。次の点も判断材料になる。

- ほかの不確かさとの比較：外出率・分担率などの係数そのものや、需要推計の前提（路線捕捉率など）の不確かさは、数%〜数十%あり、
  この差（平均0.8%・最大2.9%）より大きい。
- 手間：Bは人口データを6区分以上に変える必要がある。ただし、Q2 で「0〜4歳は数えない」（★B）を選ぶ場合は、
  0〜14歳を「5〜14歳」にするために、人口データを作り直す必要がある。その作り直しのときに、15-64歳を3区分に分けるのは、
  追加の手間が小さい（人口データの容量は、4区分から6区分で約1.5倍。全国で約110MB → 約165MB。`docs/capacity.md` の見積り550MBが約600MBになる）。
