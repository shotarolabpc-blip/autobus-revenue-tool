# 参考実績データの入れ方（F-5-5）

「推計結果」画面の「参考実績との比較」で、同梱の参考実績を一覧・検索・絞り込みして、推計と並べられます。
**いまは、都営バス（東京都交通局）の令和5年度の系統別実績126件が入っています**（東京都オープンデータの PDF〔CC BY 4.0〕から読み取り、行ごとに検算済み）。令和6・7年度のPDFも手元に取り込み済みですが、**公開用のデータには入れていません**（理由は下の「令和6・7年度について」）。ほかの事業者・自治体のコミュニティバスは、下の手順で追加できます。

東京都交通局のサイト（`kotsu.metro.tokyo.jp`）は、プログラムからの取得を拒否します。同じ資料は、東京都オープンデータの窓口（`opendata.metro.tokyo.lg.jp`）で、プログラム向けに公開されているので、そちらから取得しています。値を推測で入れることはしません。

## 令和6・7年度について（公開していない理由）

令和6・7年度のPDFは、東京都交通局の決算ページ（`kotsu.metro.tokyo.jp`）にあり、東京都オープンデータの窓口（令和5年度まで）にはまだありません。交通局のサイトポリシー（https://www.kotsu.metro.tokyo.jp/riyo/ 、2026-10-15 確認）には、掲載情報は著作権の対象で、私的使用の複製や引用など著作権法上認められた場合を除き、無断で複製・転用できないと書かれています。令和5年度のようなオープンデータ（CC BY 4.0）の表示はありません。

このツールは公開サイトに入れるため、**公開してよいと確認できるまでは、令和6・7年度を公開用データに入れていません**（`actuals_unpublished.csv` に手元だけ置いてあります）。また、令和7年度は決算の速報（監査委員の審査・都議会の認定の前）です。公開するには、交通局に利用の可否を問い合わせるか、オープンデータの窓口に令和6・7年度が載るのを待ってください。可否が分かったら、`data_build/extract_toei_actuals.py` の `publish=False` を `True` にして、2つのスクリプトを実行します。

## 都営バスの実績を作り直す（年度を更新するとき）

```bash
.venv\Scripts\python data_build\extract_toei_actuals.py
.venv\Scripts\python data_builduild_reference_actuals.py
```

`extract_toei_actuals.py` は、PDFを取得して `data_raw/reference/actuals.csv` を作ります。行ごとに「損益額＝収入−支出（千円未満の四捨五入による±2まで）」「営業係数＝支出÷収入」「系統の通し番号が欠けない」を検算し、合わないときは止まります。さらに、抜き取りで、PDFの数字と画面の数字が一致するかを人が確かめてください。

注意：乗車料収入は「千円/日」の整数で載っているため、小さい路線の平均運賃は、千円未満の丸めの影響を受けます（例：1日69千円÷390人）。便数・路線延長は、この資料にないため空欄です。

## 別の事業者・自治体の実績を入れる手順

1. 公式の資料から、路線ごとの実績を読み取る。候補（要件定義書 5.4）：
   - 都営バス「バス系統別収支状況」（東京都交通局。PDF。系統・乗車料収入〈千円/日〉・乗車人員〈人/日〉）
   - 横浜市営バス「路線別収支表」（横浜市交通局。PDF）
   - 自治体のコミュニティバスの利用実績（各自治体の地域公共交通協議会の資料）。**自動運転バスに近い規模なので、郊外・地方では主な比較対象**
2. `data_raw/reference/actuals.csv`（UTF-8）に、次の見出しで書く。**出典名・出典URL・確認日は必須**です。

   ```
   名称,事業者,種別,年度,1日乗車人員,1日便数,1日乗車料収入,路線延長km,出典名,出典URL,確認日
   ```

   - 種別：`route`（路線バス）／`community`（コミュニティバス）／`other`
   - 1日乗車料収入は円/日（千円/日で載っている資料は、1000倍する）。分からない項目は空欄でよい
   - 確認日：資料を見て値を確認した日（YYYY-MM-DD）
3. 次のコマンドで、画面用のデータにする。出典がない行などは、理由を表示して取り込みません。

   ```bash
   .venv\Scripts\python data_build\build_reference_actuals.py
   ```

4. できた `public/data/reference_actuals.json` を確認して、コミットする。

## 手元の実績を使いたいとき

事業者から入手した実績などは、「参考実績との比較」の「実績を追加」または「CSVから読み込む」で、プロジェクトに追加できます（プロジェクトファイルに含めて保存され、外部へは送りません）。
