# 参考実績データの入れ方（F-5-5）

「推計結果」画面の「参考実績との比較」で、同梱の参考実績を一覧・検索・絞り込みして、推計と並べられます。
**いまは1件も入っていません。** 公式の実績は、PDF や、自動取得を断るサイト（例：東京都交通局のサイトは、プログラムからの取得を拒否します）で公開されており、表の読み取りには人の確認が必要なためです（要件定義書 5.4）。値を推測で入れることはしません。

## 入れる手順

1. 公式の資料から、路線ごとの実績を読み取る。候補（要件定義書 5.4）：
   - 都営バス「バス系統別収支状況」（東京都交通局。PDF。系統・乗車料収入〈千円/日〉・乗車人員〈人/日〉）
   - 横浜市営バス「路線別収支表」（横浜市交通局。PDF）
   - 自治体のコミュニティバスの利用実績（各自治体の地域公共交通協議会の資料）。**自動運転バスに近い規模なので、郊外・地方では主な比較対象**
2. `data_raw/reference/actuals.csv`（UTF-8）に、次の見出しで書く。**出典名・出典URL・確認日は必須**です。

   ```
   名称,事業者,種別,年度,1日乗車人員,1日便数,1日乗車料収入,路線延長km,出典名,出典URL,確認日
   ```

   - 種別：`route`（路線バス）／`community`（コミュニティバス）／`other`
   - 1日乗車料収入は円/日（千円/日で載っている資料は、1000倍する）。分からない項目は空欄でよい
   - 確認日：資料を見て値を確認した日（YYYY-MM-DD）
3. 次のコマンドで、画面用のデータにする。出典がない行などは、理由を表示して取り込みません。

   ```bash
   .venv\Scripts\python data_build\build_reference_actuals.py
   ```

4. できた `public/data/reference_actuals.json` を確認して、コミットする。

## 手元の実績を使いたいとき

事業者から入手した実績などは、「参考実績との比較」の「実績を追加」または「CSVから読み込む」で、プロジェクトに追加できます（プロジェクトファイルに含めて保存され、外部へは送りません）。
